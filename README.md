# AXDSL Demo Add for AX8860

This project exports the `demo_add` AXDSL kernel as an AX8860 AXModel and runs it with the AX
Engine C++ API. It does not use AXCL.

The C++ program follows the same model lifecycle as `ax-samples`: initialize AX Engine, load the
model, allocate CMM input/output buffers, run inference, and verify `output == a + b`.

## Layout

```text
ax-dsl-demo-add/
├── export_demo_add.py
├── src/ax_demo_add.cc
├── models/demo_add_ax8860.axmodel
├── CMakeLists.txt
├── cmake/aarch64-none-linux-gnu.toolchain.cmake
└── build.sh
```

`models/demo_add_ax8860.axmodel` is the model generated by `export_demo_add.py`. The model has two
float32 inputs, `a` and `b`, and one float32 output, `output`, all shaped `256x512`.

## Code Structure

`src/ax_demo_add.cc` keeps the AX Engine lifecycle in small, explicit steps:

- `init_system()`: `AX_SYS_Init` for system/CMM services, then `AX_ENGINE_Init` for the NPU.
- `load_model()`: read the AXModel, create the handle/context, and query IO metadata.
- `allocate_io()`: allocate CMM buffers for every model input and output.
- `fill_inputs()`: fill deterministic input data.
- `infer()`: run `AX_ENGINE_RunSync`.
- `verify()`: compare the NPU output against the CPU reference `a + b`.
- `release()`: free CMM buffers and finalize the engine/system in reverse order.

## Prerequisites

- NPU codebase environment for exporting the AXModel
- AX8860 BSP with `include/ax_engine_api.h`, `lib/libax_engine.so`, and `lib/libax_sys.so`
- Arm GNU Toolchain 13.2 or another aarch64 toolchain with glibc >= 2.38

## Export The AXModel

Set `NPU_CODEBASE` to the checkout containing `script/npu_dev` and `axnn`:

```bash
export NPU_CODEBASE=/path/to/npu-codebase
source "$NPU_CODEBASE/script/npu_dev"
python3 export_demo_add.py
```

The default output is `models/demo_add_ax8860.axmodel`:

```bash
python3 export_demo_add.py --output models/demo_add_ax8860.axmodel
```

## Cross Compile

Set the BSP directory and put the toolchain on `PATH`:

```bash
export AX8860_BSP=/path/to/ax8860_bsp/arm64_glibc
export PATH=/path/to/arm-gnu-toolchain-13.2.Rel1-x86_64-aarch64-none-linux-gnu/bin:$PATH
./build.sh
```

The executable is written to `build/ax_demo_add`.

CMake is also supported:

```bash
cmake \
  -S . \
  -B build \
  -DCMAKE_TOOLCHAIN_FILE=cmake/aarch64-none-linux-gnu.toolchain.cmake \
  -DAX8860_BSP="${AX8860_BSP}"
cmake --build build -j
```

## Run On The Board

Copy `build/ax_demo_add` and `models/demo_add_ax8860.axmodel` to the board:

```bash
scp build/ax_demo_add models/demo_add_ax8860.axmodel root@<board-ip>:/tmp/ax-dsl-demo-add/
ssh root@<board-ip>
cd /tmp/ax-dsl-demo-add
export LD_LIBRARY_PATH=/opt/lib:$LD_LIBRARY_PATH
./ax_demo_add models/demo_add_ax8860.axmodel
```

Expected output:

```text
AX Engine version: 3.0.001
inputs: 2
  [0] a FLOAT32 256x512 (524288 bytes)
  [1] b FLOAT32 256x512 (524288 bytes)
outputs: 1
  [0] output FLOAT32 256x512 (524288 bytes)
AX Engine demo add: PASS (131072 elements, max error 0)
```
